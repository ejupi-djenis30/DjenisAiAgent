## What changed since v0.2.2

Version 0.3.0 replaces the hosted Gemini planner with local inference. DjenisAiAgent
now talks to a pre-provisioned Ollama model or a loopback OpenAI-compatible server. It
does not accept a provider API key, download a model during startup, or fall back to a
hosted service.

This is a compatibility change. Remove the former hosted-provider credential and model
settings from the deployment, then configure `DJENIS_LOCAL_LLM_BACKEND`,
`DJENIS_LOCAL_LLM_ENDPOINT`, and `DJENIS_LOCAL_LLM_MODEL`. Ollama users can also pin
the full model digest with `DJENIS_LOCAL_LLM_EXPECTED_DIGEST`.

### Runtime and deployment

- The Compose deployment now includes the agent, an unprivileged loopback gateway,
  Ollama, and Selenium Chrome on separate ingress, control, browser-egress, and
  provisioning networks.
- Model provisioning is an explicit one-time operator action. Normal startup never
  pulls model weights.
- `/health` reports process liveness. `/ready` separately checks configuration and the
  selected local runtime and model.
- The default model contract requests a 65,536-token context window. Operators can
  lower it deliberately when the target hardware cannot sustain that KV-cache cost.

### Agent behavior and safety

- The planner must return exactly one declared function call. The host validates its
  schema and arguments again before dispatch.
- Completion requires current evidence. The host distinguishes completed and blocked
  outcomes, rejects unsupported success claims, and stops repeated actions against an
  unchanged state.
- Browser destinations are checked before navigation and after redirects. Native
  process execution resolves one configured absolute executable and never invokes a
  command shell.
- Remote Selenium sessions now provide their own browser screenshot and DOM snapshot
  for the reasoning loop.

### Upgrade checklist

1. Review the new `.env.example` and remove the Gemini settings.
2. Provision a supported local model before starting the agent.
3. Keep `DJENIS_PERMISSION_TIER="observe"` until the runtime passes `/ready`.
4. Reapply only the path, application, executable, and browser-host allowlists that the
   intended tasks require.
